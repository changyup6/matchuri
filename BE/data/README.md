**저장소에 없다 (2026-09-14 부터).** EC2 의 `/home/ubuntu/matchuri-data/kakao` 에 있고
배치가 매주 갈아 끼운다. 컨테이너는 compose 가 그 폴더를 붙여 읽는다. 로컬에서 서버·
테스트·분석을 돌리려면 그 폴더를 받아 `data/kakao` 에 둔다.

EC2 배치(AI 파이프라인)가 서버에 넣기 전에 두 필드를 더한다. 없으면 서버는 예전 순서다.

| 파일 · 필드 | 뜻 |
|---|---|
| `photos.jsonl` · `hero` | `true` 인 한 장이 카드 대표 사진이다. 사진을 받아 보고 음식이며 메뉴판·가격 포스터·화면 캡처가 아니고 가장 먹음직스럽다고 고른 것. 가게마다 많아야 하나 |
| `menus.jsonl` · `popular_rank` | 손님 인기 요리 순위(0 이 1등). 같은 요리의 크기·세트 줄은 1000+순위 |

## 값을 읽을 때 알아야 할 것

- **`menus[].price` 는 56%만 값이 있다.** 카카오가 나머지를 `-1`(변동/미표기)·`0`(미입력)로
  주는데 값이 아니라 결측이라 빌드 때 `null` 로 바꾼다. 원본(`yeoksam_full/`)에는 `-1` 이
  그대로 남아 있으니 직접 읽을 때 주의할 것.
- **평점은 리뷰 탭에서만 나온다.** 검색 API 의 `rating`/`rating_count` 는 전부 0 이다.
- **리뷰가 차단된 가게가 163곳** 있다(`review_blocked_by_owner`). 사장님이 노출을 막아
  `panel3` 에는 리뷰 섹션이 아예 없지만 리뷰 탭으로는 받아진다. 이 가게들의 평균 별점은
  3.27 로 비차단(3.84)보다 낮다 — 추천에서 어떻게 다룰지는 아직 정하지 않았다.
- **사진 URL 은 대부분 네이버 CDN** 이다(129,541 / 148,380). 카카오맵이 블로그 사진을
  끌어다 보여주기 때문이고, 수집 자체는 전부 카카오맵 API 에서 했다. 핫링크는 열려 있다.
- **사진이 원본 크기(170KB~1.5MB)다.** CDN 썸네일 파라미터가 먹지 않는다.

## 출처와 범위

전부 **역삼동**(서울 강남구) 음식점이다. 2026-09-02 카카오맵 수집.

필드가 있어 남겨 뒀다. 크롤링 데이터의 이용 약관·개인정보 검토는 아직 하지 않았다.
