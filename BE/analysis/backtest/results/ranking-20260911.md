# 정렬 보정(겹치는 태그 수 · 거리) — 실서버 확인 (2026-09-11)

필터가 '누가 후보인가' 를 정한 뒤 **순서**를 두 가지가 정한다: 고른 태그와 겹치는 수(1순위 키)와
거리(점수에 섞이는 보너스). 임시 `MATCHURI_STATE` · 포트 8019 · interleave 로 띄워 세 경우를
확인했다. 위치는 모두 역삼역(37.5006, 127.0366)이다.

```bash
cd server && MATCHURI_STATE=… MATCHURI_DIST_WEIGHT=0.4 uvicorn main:app --port 8019
curl -X PUT .../users/{id}/location -d '{"lat":37.5006,"lon":127.0366}'
curl -X PUT .../users/{id}/filter   -d '{"tag":["단체모임","분위기"]}'
curl '.../cards?user_id={id}&limit=10'
```

### 거리가 정말 순서를 바꿨나 — 무게 0 과 0.4 비교

같은 설정(역삼역·`혼밥`)으로 **거리를 끈 서버**(`MATCHURI_DIST_WEIGHT=0`)와 기본값 서버에서
각각 새 사용자로 20장을 받았다.

| | 평균 거리 | 중앙값 | 최대 |
|---|--:|--:|--:|
| `MATCHURI_DIST_WEIGHT=0` (대조군) | 698m | 765m | 1095m |
| `MATCHURI_DIST_WEIGHT=0.4` (기본) | 472m | 491m | 971m |

대조군 20장: 64m, 581m, 328m, 971m, 704m, 776m, 753m, 854m, 600m, 1095m, 1076m, 300m, 599m, 973m, 491m, 824m, 937m, 765m, 344m, 915m
기본값 20장: 64m, 328m, 581m, 300m, 776m, 66m, 971m, 86m, 854m, 344m, 278m, 291m, 599m, 349m, 693m, 491m, 824m, 600m, 752m, 200m

무게만 바꿨는데 평균이 698m → 472m 로 내려갔다
(32% 가까워졌다). 거리는 **벽이 아니라 점수**라서 먼 곳도
여전히 나올 수 있다(취향 점수가 충분히 높으면) — 그게 `within_m` 과 다른 점이다.
