# 측정 전에 고정하는 비교 논리

사용자 목표: 같은 현재 상황에서 과거 취향이 미세한 순위 차이로 남는지 실제 가게 데이터로 설명한다. 7:3, 첫 카드 반전, 선호 스타일 과반은 합격 조건이 아니다. 운영과 연구 모델은 구분하며 이번 측정에 맞춘 모델/정책 튜닝은 하지 않는다.

1. 돈까스: 기존 현재20회(4좋아요)6seed를 고정한다. 과거없음, 동수 이력의 편향없는 반응, 일식/한식/중식/양식 반응을 비교한다. 과거40곳은 cuisine별10곳, 좋아요는 선호8/10+나머지각4/10=20, 중립각5/10=20이다. 같은가게/순서에서라벨만바꾸며4⊂5⊂8을보존한다. 과거에서는수집자료의돈까스근거가있거나현재/평가브랜드가겹치는가게를제외한다. 과거가없는것과카테고리편향이없는것은다른대조군이다.
2. 형태: 밥/면은주식형태, 육류/해산물은주재료로원래배타적이지않다. 원천메뉴감사로형태중심이명확한과거참조와중첩태그를구분한다. 당초다른3cuisine×4형태의균형N48을검토했으나모델점수를보기전메뉴감사에서W밥/C밥/해산물등셀이부족하여채택하지않는다. 현재cuisine각각에대해과거donor cuisine를하나로고정해그cuisine교란을통제하는대안을사용한다. 같은형태별m가게×4,N=4m. m은원천감사/브랜드제약으로사전결정하고모델점수로선택하지않는다. m5이면fav4/5·others2/5(10/20좋아요),neutral은각2또는3개로두그룹씩6seed의가능6조합을순환한다. m3이면fav3/3·others1/3(6/12좋아요),neutral각1또는2개로같이순환한다. N/반응대비강도차이가있으면직접효과크기비교를하지않는다.
3. 형태현재조건은동일cuisine의혼합/미확정주력메뉴식당4곳좋아요+타cuisine16곳싫어요로20회고정한다. 이것은강한현재cuisine를주입한통제실험이며자연사용자반응비율의추정이아니다. 과거/현재/평가는확인된브랜드까지분리한다. 평가참조는모든arm에서같고원본후보수차이를추천에서보정하지않는다.
4. 연구모델은proper-intercept 시간커널GP를고정한다. 연구full과기존현재하한선택기, 현재운영taste/decision 핵심경로를별도로재생한다. 원본벡터를고차원공간으로변환하는방법과시간상수는이전과동일하다. 라벨은가정반응/측정에만사용하며모델특징, 후보제한,추천quota에사용하지않는다.
5. 주효과는같은이력양neutral대비고정미학습참조군의상대점수변화다. N0대비는보조. 전체top10/20·실제decision4·현재조건안top10·미학습현재조건안top10을분리한다. 후자의조건부성공을실제네장성공이라고말하지않는다. 그룹별원래가게수/미학습수/실제진입수/관측브랜드를내보낸다. 돈까스의K/C고유스타일정답을만들지않고J/W·혼합/불명과실제가게변화로표현한다.
6. 계산검사: 동일ID/order 이력arm의GP std 동일,모든arm 현재-only 평균/std/기준4장/하한 동일. 실제4317D계수로전체평균을재구성. 코드/입력SHA를실행전후확인. 평가라벨/현재입력누출·실수한브랜드중복은점수를보기전에고친다.
7. 모든조건을보고하며좋은사례만골라성공률을내지않는다. 6seed가같은가게를재사용하므로독립사용자6명이나유의성확인으로표현하지않는다. 그림은실제계산수치이며가정입력임을명시한다.

추가 명시: 형태 neutral은 개별 seed마다 홀수 그룹의 2/3(또는1/2) 반응 수 차이가 있으며, 가능한 여섯 조합을 모두 사용한 집계에서만 각형태50%다. 본측정의 형태 대비는 주력형태(primary) 기준이다. 복수형태 태그는 별도 후보 수/카드 구성 자료로 내보내고, 서로겹치는태그비율을합쳐100%나독립정답으로해석하지않는다. 원본감사들의중복source SHA가다르면측정을거부한다.
