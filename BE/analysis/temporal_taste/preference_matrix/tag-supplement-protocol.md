# 중첩 메뉴 태그 보조 진단 (점수 출력 열람 전 고정)

주력 형태가 확인되지 않아도 수집 메뉴에는 밥/면/육류/해산물이 등장할 수 있다. 중국식 밥주력0은 밥메뉴있는가게0을 뜻하지 않는다. population-coverage.json은 점수와 독립적인 실제 원천 태그 수다.

고정 fixtures의 같은 current cuisine/heldout 집합에서 각 태그에 속한 가게의 평균 점수 - 전체 heldout current cuisine 평균 점수를 계산한다. 같은N neutral대비 이 값의 변화와 tag가있는가게의 실제4장/조건부top10 진입 수를 보고한다. 중첩태그들의 비율은 합쳐100%가 되지 않는다. 태그가없다는것을실제미판매로단정하지않는다. 이 검사는 '밥을주력으로하는식당'의 정답 검사와 다르며, 다른메뉴도함께있는가게 집합에 대한 기술통계다. 주력형태의 NA를 태그검사로 바꾸어 전체성공률을부풀리지않는다.
