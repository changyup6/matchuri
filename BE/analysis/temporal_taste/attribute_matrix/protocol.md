# 음식·속성 교차 측정 사전 규약

사용자 목적은 같은 현재 식사 상황에서 이전 취향이 미세한 세부 순위로 남는지 다양한 음식·속성에서 확인하는 것이다. 특정 국가/속성 비율이나 큰 효과를 합격 조건으로 정하지 않는다. 운영·연구 모델과 후보 점수·최종 네 장을 구분한다.

이 규약은 새 모델 점수를 보기 전에 작성한다. 추천 모델·시간상수·선택 규칙은 기존 값을 동결하며 이번 라벨은 실험 입력/검산에만 사용한다. 측정 기준 최신 master는 b8a4f25다. 운영 카탈로그1,498곳의 원본 파일 SHA를 동결한다.

## 축과 근거

현재 음식은 돈까스 외 면·밥·국(국/탕/찌개/전골), 가능한 구이·샐러드까지 포함한다. 가게의 복수 음식 제공은 허용하되 공기밥/사리/소스/음료를 주력 식사로 세지 않는다. 음식명·명시 설명으로 확인한 맛/조리법/온도/재료/식감/식사양상, 검증된 요리권과 원천 카테고리를 서로 다른 평가 축으로 둔다. 자료가 충분하지 않으면 미측정으로 남긴다.

속성은 관측된 메뉴 수준의 가게 증거다. 실제 주문 메뉴나 방문자의 잠재 선호 정답이 아니다. 부정문·맵기 선택·사이드·교차 재료를 기록하고 명시 단어와 선언된 음식명 사전 추론을 구분한다. 단어가 없다는 사실을 반대 맛/조리법의 증거로 쓰지 않는다. 메뉴 대표성/중복 속성 때문에 확정할 수 없는 순수 효과를 주장하지 않는다.

## 대조 설계

각 현재 음식 × 속성 A/B 조합에서 A만 관측된 가게와 B만 관측된 가게를 대조한다. 두 속성이 함께 있는 가게는 이 상대 비교에서 제외한다. 원래 후보군 수와 관측/미학습 가게 수를 별도로 공개한다. 모집단 차이를 추천 할당 비율로 보정하지 않는다.

현재20반응은 해당 음식의 A측2곳+B측2곳 좋아요, 그 음식의 근거가 없는16곳 싫어요로 구성한다. 이는 현재 식사 상황을 명확히 주입한 가정 반응이며 자연 사용자 분포가 아니다. 같은 조합·seed에서는 모든 과거선호 조건에 같은현재반응·순서·평가모집단을 쓴다.

과거는 A/B 같은 수의 가게를 사용한다. 가능한 경우 각8곳(N16), 그보다 부족하면 각4곳(N8)을 점수 전에 결정한다. 가게 수 선택은 자료와 브랜드 분리만을 기준으로 한다. 중립은 각절반, A선호는 A3/4·B1/4, B선호는 반대 비율로 좋아요해 총 좋아요 수를 고정한다. 이력 없음도 별도 비교한다. 과거 가게·순서는 선호조건마다 동일하며 반응만 바꾼다.

주요 전이 검사는 과거 가게가 현재 음식 context 밖인 cross_food 방식이다. 해당 맥락의 원천 세부 카테고리 일반화는 heldout_category로 따로 표시하고 현재 음식의 과거 가게를 허용한다. 이를 다른 음식에 잠재 취향이 전이된 증거로 부르지 않는다.

과거/현재 가게 및 브랜드는 분리한다. 고정 미학습 평가는 과거·현재의 브랜드를 제외하고 양쪽 최소2브랜드를 요구한다. 최소2는 측정 가능 조건일 뿐 강한 증거 기준이 아니며 5브랜드 미만은 희소 집단으로 표시한다. 가능 여부·제외 이유·실제 표본 수를 모두 공개한다. 6개 고정seed에서 재생하며 같은 카탈로그를 재사용하므로 독립 사용자6명이나 신뢰구간으로 해석하지 않는다.

## 무엇을 측정하고 어떻게 읽는가

- 같은 현재 반응에 과거 선호만 바꿨을 때 고정 미학습 A/B 가게의 평균 점수차 및 중립 대비 이동을 비교한다. A선호는 A쪽, B선호는 B쪽 이동을 별도로 센다. 양수율을 선호 예측 정확도라고 부르지 않는다.
- 실제최종4장, 전체top10, 현재 음식 내부top10을 분리해 A/B/현재음식의 실제 가게 수와 순위 이동을 보여준다. 조건부top10을 최종추천률로 쓰지 않는다.
- 이미 좋아요한 가게 재등장, 관측싫어요 재등장, 새로운가게·브랜드를 구분한다. 현재상황보존 증가가 신규발견 개선인지 따로 판단한다.
- 실제4,317차원 계수의 거리/각도/내적 점수 이동을 저장하되 좌표에 임의의 음식 의미를 붙이지 않는다. 운영모델 점수와 연구모델 점수의 크기를 직접비교하지 않는다.
- 빈셀·반대방향·약한효과를 남긴다. 어떤특성을 더 잘 구분한다는 결론은 해당가게들의 카테고리/다른속성 상관관계와 표본크기를 함께 보고 제한한다. 다중 비교의 일부양수를 통계적유의성이나 보편효과로 주장하지 않는다.

## 결과 무결성

실행 전 source SHA, 라벨, fixture, 코드 동결. 실행 후 SHA 일치, matched-current 결과동일, label-only GP 불확실성동일, 4장고유성/카탈로그적합, 벡터→평균 재구성 검산. 별도집계로 CSV분모/점수/방향/카드 재검산. 운영 사용자DB는 읽거나 수정하지 않고 임시상태로 실행한다. 원본메뉴/리뷰/카탈로그벡터는Git에 넣지 않는다.

## 사전 표본 구성 보완 (모델 점수 조회 전)

각 음식은 주력/공동주력 core와 독립 메뉴 제공 menu 두 범위를 별도로 재생한다. menu의 결과는 해당 음식 전문점 추천 성과가 아니다. 과거 다른음식 전이는 side-only를 제외한 실제 음식 신호 전체 밖에서만 뽑는다. 현재 싫어요도 같은 음식 신호 밖에서 뽑지만 신호 부재가 실제 판매 부재를 뜻하지는 않는다.

요리권 자체와 원천 카테고리를 비교하는 경우를 제외하고, 과거A/B와 현재좋아요A/B는 원천cat2가 같은 가게끼리 짝지어 요리권 구성 차이를 줄인다. 이 조건에서 사례를 만들지 못하면 미측정으로 남긴다. 나머지 속성 상관관계까지 제거한 순수 인과효과는 아니다.

구체적26대조쌍과6음식·두범위는 build-fixtures.py specs에 정의한다. 매운/순한 근거처럼 희소한 경우 숫자를 채우기 위해 무표현 가게를 반대 속성에 넣지 않는다. 분류·샘플링 가능성만으로 N16 또는 N8을 결정하고6seed 모두 브랜드/현재/미학습 분리가 가능한 경우만 실행한다.

속성 감사에서 plant_protein 보조태그에 두부/콩뿐 아니라 채식 문구가 포함됨을 확인하여 해당 대조쌍은 모델 실행 전에 제외했다. 관측된 단백질 성분의 순수 비교라고 해석할 수 없기 때문이다. 추출된26태그와 실제대조에 쓰는태그 수는 구분한다.

## 모델 실행 전 대조 구성 감사에서 보완한 사항

점수/추천을 계산하기 전에 current 긍정 반응의 마지막이 B로 고정되어 있음을 발견해 짝수seed A-B-A-B, 홀수seed B-A-B-A 순서로 균형화했다. 긍정 위치3/8/13/18과 모든가게집합은같다. 과거에서는 각A/B짝마다정확히1좋아요를보장해cat2별좋아요총량도조건간동일하게했다. A군앞na개좋아요/B군나머지좋아요 방식이며중립/선호/반대선호의군별좋아요비율·총반응수는그대로다. 기존안과변경안의가게/평가집합동일성을별도로검사한다.

이 수정 전 가게집합의 고차원평균방향 진단은 계산했지만 추천모델점수나실제카드결과는아직계산하지않았다. 진단은반응레이블/순서에의존하지않으므로새안에서도값이동일해야한다. 이전입력과해시는prebalance에보존한다.
