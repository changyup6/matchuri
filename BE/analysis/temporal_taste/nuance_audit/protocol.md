# 사전 명시한 재평가 범위

목표: 현재 상황을 유지하면서 관련 후보 내에서 과거 선호가 작게 순위/노출 경향을 바꾸는지. 첫 카드 변경, 선호 스타일 과반, 7:3 할당은 성공 조건이 아니다. 실제 후보 수/품질 차이를 제거하여 운영 할당하지 않는다.

1. 고정된 948개 기존 측정과 222개 정책 비교를 재해석한다. 모델/하이퍼파라미터/라벨/현재 반응은 변경하지 않는다.
2. 과거 N0 대비와 반대 과거 대비를 함께 본다. 실제 top10/top20/최종4/첫1을 분리하고, 정확한 미관측 비교군의 평균 점수 차이와 순위를 분리한다.
3. 확정 스타일 가게의 모집단(돈까스6/6, 국물면20/28)과 미확정/혼합 집합을 별도로 기록한다. 균형 쌍별 우위는 진단값이지 원하는 노출 비율이 아니다.
4. 후보 수 조건을 확인하기 위해, 고정된 미관측 돈까스4+4 집합에서 J2/W4·J4/W4·J4/W2의 실제 가게 부분집합을 전수 조합한다. 같은 subset에서 N0/J/W 점수로 top3를 고른다. 새 가게/벡터를 복제하지 않으며 학습은 그대로다. 이는 후보 밀도 조건을 고립한 사후 진단이며 운영 추천률이 아니다. mean와 mean−0.5sd를 따로 보고한다. 과거 N10/20/40/80을 모두 기록한다.
5. selector의 실제 단계와 first-anchor 고정/다양성/양수 게이트가 미세 변화에 미치는 역할은 동일 frozen posterior로 추적한다. 정책/가중치 튜닝은 하지 않는다.
6. 기술적 가능성과 현재 증거를 구분한다. 오래 지속되는 성향과 현재 상황의 분리에는 반복된 상황/선택 근거 및 관련 특성 공유가 필요하며, 미노출과 싫어요를 혼동하지 않는다.
